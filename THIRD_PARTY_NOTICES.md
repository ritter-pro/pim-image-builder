# Сторонние компоненты

Включён шрифт DejaVu Sans; лицензионные сведения сохранены в assets/FONT-LICENSE.txt.

PyMuPDF, Pillow, NumPy и pypdf устанавливаются отдельно из requirements.txt. У каждой зависимости собственные условия использования; её код не скопирован в репозиторий.

Материалы demo созданы специально для публичного примера и не являются документами компании. Встроенный контур цилиндра создан в ходе проекта по силуэту лампочки; исходная фотография и логотип не публикуются.

Лицензия на собственный код проекта пока не установлена. Этот файл не заменяет лицензию на код.
